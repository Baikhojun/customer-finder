# 🎯 Customer Finder — 내 업무의 진짜 고객 찾기

> 디자인 씽킹의 **공감(Empathize) + 정의(Define)** 단계를 카드 게임으로.
> "내 업무는 사실 누군가에게 결과를 넘기는 일이다 — 그 누군가를 찾는다."

made by **WhiteJune** · AI 활용 2차 TF 자체 교육 (2회차 1교시 후반, 약 20분)

---

## 🌟 이 게임을 하는 이유

도구를 만들려면 보통 "어떻게 만들까"부터 생각합니다.
하지만 진짜로 쓸 만한 도구가 되려면 먼저 **"누구의 어떤 문제를 풀건가"**가 명확해야 합니다.

- ❌ "엑셀 양식 자동화해야지" → 누구를 위한 양식인지 모르면 결국 안 쓰임
- ✅ "**회계팀**이 매번 양식이 달라 짜증나니까, 양식 자동 생성기" → 명확

이게 디자인 씽킹의 첫 단계, **공감(Empathize)**입니다.

---

## 🎮 게임 흐름 (20분)

1. **닉네임** 입력 + 타이머 시작
2. 좌측 팔레트에서 카드 선택:
   - 👤 **Who 1장** — 내 결과물을 받는 사람
   - 💢 **Pain 3장** — 그 사람의 진짜 불편
   - 🎁 **Gain 3장** — 내 도구가 줄 좋은 변화
3. 자동 생성된 **한 문장**을 (필요하면 직접) 다듬기
4. **✅ 완성!** 누르면 갤러리에 저장 + 인사이트 표시
5. **🖼 갤러리**에서 다른 사람과 비교 / 우리 팀 분포 확인
6. **💾 PNG** 또는 **📝 MD**로 다운로드 → 다음 시간 흐름도의 출발점

---

## 🃏 카드 라이브러리 (3 카테고리 × 30장)

| 카테고리 | 카드 |
|---|---|
| 👤 **Who** (10) | 회계팀·상사·임원·현장 담당자·임직원·외주사·감사실·결재권자·시설팀·민원인·다른 시스템 |
| 💢 **Pain** (10) | 응답 늦음·진행상황 모름·또 물음·양식 매번 다름·반려 사유 불명·시작법 모름·시즌 폭증·표 깨짐·데이터 옮김·첨부 누락 |
| 🎁 **Gain** (10) | 5분에 끝·한 번에 통과·자동 알림·양식 일관·핵심 한눈·진행 투명·두 번 안 물음·야근 줄음·신규자 사용·상사 칭찬 |

> 카드에 없으면 **＋ 직접 추가** 버튼으로 본인 업무 맞춤 카드 작성 가능.

---

## 🪟 갤러리 3가지 모드

| 모드 | 용도 |
|---|---|
| **격자 보기** | 우리 팀 모든 작품을 한눈에 — "각자 누구를 보고 있나?" |
| **두 작품 비교** | 두 사람 작품을 좌우로 펼침 + 자동 인사이트 ("두 분은 다른 고객을 보고 있네요" 등) |
| **📊 우리 팀 분포** | 가장 많이 선택된 고객·불편·변화를 막대 그래프로 — **공통 고통 발견**의 시각화 |

## 🎓 AI 활용 2차 TF 교육과의 연결

| 회차 | 이 게임이 채우는 부분 |
|---|---|
| 1회차 산출물 | "업무 맥락 정의서"를 **사용자 관점**으로 다시 씀 |
| 2회차 | Mermaid 흐름도 그리기 전, **"왜 이 흐름이 필요한가"** 확보 |
| 2회차 후반 | micro-tool-interviewer 인터뷰의 **타깃 사용자** 명확화 |
| 3회차 | HTML 도구 v1의 **존재 이유**(한 줄 비전) 확정 |

## 📁 프로젝트 구조

```
customer-finder/
├── index.html              # 진입점
├── style.css               # Yooshin 폰트 + 토스트 톤
├── README.md
├── assets/
│   ├── favicon.ico
│   └── fonts/              # Yooshin Bold / Medium
└── js/
    ├── cards-data.js       # Who/Pain/Gain 30장
    ├── palette.js          # 좌측 카드 팔레트
    ├── slots.js            # 1+3+3 고정 슬롯 캔버스
    ├── sentence.js         # 한 문장 자동 생성 + 인라인 편집
    ├── timer.js            # 카운트다운 타이머
    ├── stats.js            # 사이드바 통계
    ├── gallery.js          # localStorage 갤러리 + 비교 + 팀 분포
    ├── export.js           # PNG + MD 다운로드 (Yooshin 폰트 임베드)
    └── main.js             # 전체 초기화 + 도움말 + 닉네임 편집
```

순수 HTML/CSS/JS — 빌드 도구 없음. Draw Toast의 모듈 패턴을 재사용.

## ⌨️ 단축키 / 조작

| 행동 | 방법 |
|---|---|
| 카드 추가 | 팔레트에서 카드 클릭 → 해당 카테고리 슬롯에 추가 |
| 카드 제거 | 슬롯의 채워진 카드 클릭 |
| 닉네임 변경 | 헤더의 닉네임 칩 클릭 → 인풋으로 전환 |
| 직접 카드 추가 | 좌측 ＋ 직접 추가 버튼 |
| 한 문장 직접 수정 | "✏️ 직접 수정" 버튼 (Ctrl+Enter로 저장) |
| 도움말 | 시작 화면 또는 헤더 ❓ 도움말 |
